# ドパガキマインスイーパー（SwiftUI）

デザイン案「脳汁ネオン・ステッカー」をもとにした iOS アプリです。

## 動かし方

1. `DopagakiMinesweeper.xcodeproj` を Xcode 16 以降で開く
2. Signing & Capabilities で自分の Team を選ぶ
3. iPhone シミュレータか実機で実行（iOS 17 以降）

## 見出しフォント（任意）

見出しは Google Fonts の **Dela Gothic One**（OFL ライセンス）を想定しています。

1. https://fonts.google.com/specimen/Dela+Gothic+One から `DelaGothicOne-Regular.ttf` をダウンロード
2. `DopagakiMinesweeper/Fonts/` フォルダを作って ttf を入れる

フォルダに入れるだけで自動で読み込まれます。入れない場合は、システムの丸ゴシック（極太）で表示されます。

## 遊び方とドーパミン要素

- タップで開く。長押しか「旗モード」で旗を立てる。数字をタップすると周囲を一括で開く
- 初手は必ず空白マスになり、大きく連鎖して開く
- 2秒以内に開け続けるとコンボが続き、音程が上がっていく
- 一度に10マス以上開くと CHAIN ボーナス。15マス以上で画面が揺れる
- フィーバーゲージが満タンになると8秒間スコア2倍
- レーダー（地雷に自動で旗）2回、復活1回
- クリアでランク（S〜C）、XP、コインを獲得し、レベルとステージが上がる
- 設定で効果音、振動、画面の揺れをオフにできる。端末の「視差効果を減らす」がオンの場合は揺れと紙吹雪を出さない

## 刺激モード

タイトルの「刺激モード」から遊べる、クリッカー風のエンドレスモードです。

- マスを開けるたびに「刺激」がたまる。コンボと連続クリア倍率で増える。クリアするとボーナス、すぐ次の盤面が出る
- 地雷を踏んだとき、連続クリア中か盤面の4割以上を開けていれば「広告を見て復活」できる（中身はうその広告。スキップボタンは逃げる）
- ラスト1マスになると心音と赤いふちで緊張感を出す
- ショップ（右上のカート）で刺激を使って買い物をする。買うほど画面がうるさくなり、毎秒の刺激も増える
- 「デジタルデトックス」以外は何回でも買える（1個ごとに値段が1.15倍、脳汁ブースターは1.4倍）。×1 / ×10 / MAX のまとめ買いができる。数が増えるとロゴ・小窓・鳥・生き物が増える、量や速さが上がるなど演出も強くなる（画面に出す数には上限あり）
  - 脳汁ブースター / DVDロゴ（角に当たると大当たり） / ラッキーマス（開けると×10） / 通知（タップで刺激） / 弾幕コメント / ニュース速報 / ローファイBGM / 謎の生き物（ごはんで倍率、放置で泣く） / ゲーム実況 / スロットマス（そろうと自動で連鎖） / 株チャート / 画面バキバキ（大連鎖でヒビ、クリアで修理） / 雨音ASMR / 投げ銭（タップで回収） / 絵文字シャワー / 勉強しろ鳥 / ガチャ / 実況ボイス / ゲーミング背景
- 魚育成：「水槽」を買うと魚が飼える（1個で5匹）。卵を買うか、クリア・ラッキーマス・スロットで拾う。卵はN/R/SR/SSRの12種からランダム。マスを開けると全部の魚が育ち（卵→稚魚→若魚→成魚）、エサで一気に育つ。おなかが空くと成長が止まるが死なない。育った魚は毎秒の刺激を生み、画面を泳ぐ（最大20匹、1匹ずつ表示を切り替え可）。盤面の後ろか前かは水槽タブで切り替え。名前をつける、放流する、図鑑もある。転生しても魚・図鑑・水槽は残る
- 10分ごとに2分間の「脳汁2倍フェス」（時計で決まる）
- 毎日のログインボーナス（7日目は10倍）と、閉じていた間の放置収益（最大8時間、広告で2倍）
- 実績27種。解除するとボーナス
- 転生：今回の周回で2万以上稼ぐと、刺激と商品を手放してずっと残る倍率（+10%/ポイント）をもらえる
- 最後の商品「デジタルデトックス」を買うとエンディング。そこから転生してもう一度遊べる
- BGM・心音・雨音・ボイスは効果音の設定に従う。進行は端末に保存される
- 以前の「自動ほりほりBot」は廃止。買っていた場合は使った刺激を返金する


## Web版

`web/index.html` は iOS版と同じ内容（タイトル、通常モード、刺激モード）をブラウザで遊べる1ファイルのWebアプリです。依存はなく、ファイルを開くだけで動きます（見出しフォントは Google Fonts から読み込み、読めないときは太いシステムフォントで代用）。

- スマホは縦向きで、タップで開ける・長押しで旗。パソコンはクリックで開ける・右クリックで旗
- 効果音・BGMは Web Audio で合成、実況ボイスはブラウザの読み上げ、振動は対応ブラウザのみ
- 進行はブラウザの localStorage に保存（iOS版とは共有しない）
